# Portal Jarbas Cardoso

Portal do condomínio: rateio mensal, recibo por apartamento (com código de acesso), mural de avisos e histórico.

- `index.html`: o portal.
- `dados.json`: rateios, avisos, pagamentos e configurações. O modo colaborador atualiza este arquivo pelo botão **Publicar**.

## Publicar pelo modo colaborador

O botão Publicar usa um token do GitHub salvo só no aparelho do colaborador (Configurações → Publicação no GitHub).
Crie o token em GitHub → Settings → Developer settings → Fine-grained tokens, com acesso apenas a este repositório e permissão **Contents: Read and write**.
